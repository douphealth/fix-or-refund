# Fix or Refund? (`fixorrefund.shop`) — 2026 Redesign & SEO/AEO/GEO Bundle

Drop-in static bundle for **https://github.com/douphealth/fix-or-refund** (Cloudflare Pages / GitHub Pages ready, zero build step required).

## Included Files
- `index.html` — Redesigned bilingual (EN/EL) interactive EU-27 Rights Checker, 2026 Right to Repair +12-Month Simulator, EU-27 Country Explorer, Claim Letter Generator, AEO Direct-Answer FAQ Hub, and full JSON-LD `@graph`.
- `robots.txt` — Search & AI crawler permissions (Googlebot, Bingbot, GPTBot, ChatGPT-User, OAI-SearchBot, ClaudeBot, PerplexityBot, Google-Extended).
- `sitemap.xml` — XML sitemap with `xhtml:link` hreflang annotations.
- `llms.txt` & `llms-full.txt` — Generative Engine Optimization (GEO) manifests for LLM citation accuracy.
- `_headers` — Cloudflare Pages security, caching, and content-type headers.

## Quick Push to GitHub
```bash

cd fix-or-refund
```
